## 5. README 最低要求（开发完成后填写）

1. 环境：JDK 17+、MySQL 8.0+、Maven、Node 18+
2. 建库：`mysql -u root -p < sql/init.sql`
3. 后端：`cd backend && mvn spring-boot:run`（端口 8080）
4. 前端：`cd frontend && npm install && npm run dev`
5. 默认测试账号（若使用种子数据）：alice / 123456
